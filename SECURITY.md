# Security

The course is a static site: no server, no accounts, and progress is stored only in your own browser's `localStorage`.

If you find a security problem, such as a way to run script through the content or a link that points somewhere unsafe, please report it privately using [GitHub's private vulnerability reporting](https://github.com/Xaib026/zero-to-ai-engineer/security/advisories/new) rather than a public issue. You should hear back within a week.
